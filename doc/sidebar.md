# 左侧侧边栏产品方案

> 版本：v1.0（待确认）
> 更新：2026-08-16
> 目标：重构主对话页的信息架构，新增可伸缩左侧边栏，统一收纳「会话管理 / 文件上传 / 知识库 / 记忆」等入口。

---

## 一、背景与目标

当前主对话页存在两个问题：

1. **入口分散**：会话管理（Header 的「会话 badge」）、结构输入（InputBar 附件）、长期记忆（Header「记忆」→ MemoryPanel 弹层）散落各处，没有统一的资源导航。
2. **Header 冗余**：`Planner → Executor → Critic` 是后端内部编排流程，对用户无意义，需移除。

**目标**：新增左侧可伸缩侧边栏，把「对话 + 资源 + 账户」收纳到统一入口，对齐 ChatGPT / Claude / Kimi 的主流布局——**对话在中间，资源在左侧，账户在底部**。

---

## 二、侧边栏整体布局

```
┌─────────────────┐
│ [Logo  QAP]  ⇤   │  ← 顶部：品牌 + 收起按钮
├─────────────────┤
│ [+ 新建对话]     │  ← 会话区（P0）
│ ───────────      │
│  苯的优化    …   │
│  甲醛吸收谱  …   │
│  Ni 频率     …   │
│  (历史对话列表)   │
├─────────────────┤
│ ▣ 拖拽上传区      │  ← 资源区（P0）
│  .xyz/.mol/.pdf  │
│  ───────────      │
│  已上传文件列表   │
│  知识库入口       │  ← 资源区（P2）
│  工具清单入口     │  ← 资源区（P2）
├─────────────────┤
│  记忆中心         │  ← 底部（P1）
│  设置            │  ← 底部（P2）
│  guest  · 退出   │  ← 底部（P0）
└─────────────────┘
```

| 状态 | 宽度 | 表现 |
|------|------|------|
| 展开 | ~260px | 完整图标 + 文字 |
| 收起 | ~56px | 仅图标，hover 显示 tooltip |

## 三、功能需求明细

> 每条标注：优先级（P0 必须有 / P1 重要 / P2 可选）、前端组件、对应接口。

### 3.1 顶部区

| 需求ID | 需求描述 | 前端组件 | 接口 | 优先级 |
|--------|---------|---------|------|--------|
| SB-01 | Logo + 产品名，点击回默认对话 | SidebarHeader | 无 | P0 |
| SB-02 | 收起/展开切换，状态本地记忆（刷新保持） | SidebarHeader | 无（localStorage） | P0 |

### 3.2 会话区

| 需求ID | 需求描述 | 前端组件 | 接口 | 优先级 |
|--------|---------|---------|------|--------|
| SB-10 | **新建对话**：一键开新会话，清空当前消息 | NewChatButton | 前端重置 session_id | P0 |
| SB-11 | **历史对话列表**：按时间倒序展示当前用户所有会话 | ConversationList | `GET /api/conversations`（新增） | P0 |
| SB-12 | 会话项展示：标题（取首条消息摘要）+ 相对时间 + 活跃高亮 | ConversationItem | 同 SB-11 | P0 |
| SB-13 | 切换会话：点击加载该会话历史消息 | ConversationItem | `GET /api/conversations/{session_id}/messages`（新增） | P0 |
| SB-14 | 会话操作：hover 出现「重命名 / 删除」 | ConversationItem | `PATCH` / `DELETE /api/conversations/{session_id}`（新增） | P1 |
| SB-15 | 会话搜索：按标题关键字过滤 | ConversationSearch | 前端过滤（或接口参数） | P2 |
| SB-16 | 会话分页/滚动加载：会话多时不一次性拉全 | ConversationList | 接口分页参数 | P1 |

**交互流**：

```
点击「新建对话」→ 重置 session_id，清空消息区，输入框聚焦
点击历史项 → 拉取该 session 消息 → 渲染到消息区，切换活跃高亮
删除会话 → 二次确认 → 调 DELETE → 列表刷新（当前会话被删则自动开新会话）
```

### 3.3 资源区（文件拖拽上传）

| 需求ID | 需求描述 | 前端组件 | 接口 | 优先级 |
|--------|---------|---------|------|--------|
| SB-20 | **拖拽上传**：拖文件到侧边栏 dropzone（或对话区）自动上传 | UploadDropzone | `POST /api/upload`（新增） | P0 |
| SB-21 | 文件类型识别与分流：结构文件 / 文档 | UploadDropzone | 前端按扩展名 + 后端校验 | P0 |
| SB-22 | 上传进度与状态：进度条 / 成功 / 失败 | UploadItem | 上传接口返回 | P0 |
| SB-23 | 已上传文件列表：可点击「引用到当前对话」 | FileList | `GET /api/files`（新增） | P0 |
| SB-24 | 文件删除 | FileList | `DELETE /api/files/{file_id}`（新增） | P1 |
| SB-25 | 结构快捷输入：粘贴 XYZ / 输入 SMILES（不落盘，随对话提交） | StructureInput（并入侧栏） | 随 `POST /api/workflow/stream` | P1 |

**文件类型分流规则**：

| 类别 | 扩展名 | 去向 |
|------|--------|------|
| 结构文件 | .xyz / .mol / .sdf / .gjf / .com / .pdb / .cif | 上传后可「引用」为当前对话的分子输入 |
| 知识文档 | .pdf / .txt / .md / .docx | 上传后进入知识库（触发 RAG ingest，K1） |

> 说明：结构文件与知识文档物理上都走 `POST /api/upload`，由后端按扩展名决定存储位置（结构文件存临时目录，文档走 rag ingest），前端在列表里用图标区分。

### 3.5 底部区

| 需求ID | 需求描述 | 前端组件 | 接口 | 优先级 |
|--------|---------|---------|------|--------|

## 四、伸缩交互规格

- **收起/展开**：点击顶部 `⇤/⇥` 按钮切换；状态存 `localStorage`，刷新保持。
- **收起态**：仅显示图标，hover 图标显示 tooltip 提示文字。
- **响应式**：视口宽度 < 768px 时默认收起。
- **拖拽热区**：展开态为侧边栏顶部固定 dropzone；同时支持拖到对话区任意位置（拖入时高亮）。
- **与主区关系**：侧边栏与 Header / 消息区 / InputBar 三栏式布局（侧边栏 + 主对话列），侧边栏伸缩时主区自适应。

## 六、后端新增接口清单（联调期需实现）

| 方法 | 路径 | 用途 | 对应需求 |
|------|------|------|---------|
| GET | `/api/conversations` | 当前用户会话列表 | SB-11/12 |
| GET | `/api/conversations/{session_id}/messages` | 某会话历史消息 | SB-13 |
| PATCH | `/api/conversations/{session_id}` | 重命名会话 | SB-14 |
| DELETE | `/api/conversations/{session_id}` | 删除会话 | SB-14 |
| POST | `/api/upload` | 文件上传（结构/文档分流） | SB-20~22 |
| GET | `/api/files` | 已上传文件列表 | SB-23 |
| DELETE | `/api/files/{file_id}` | 删除文件 | SB-24 |

> 会话列表数据源：当前 Redis 仅按 session_id 存消息（`get_history`/`save_history`），需后端新增一个 `user_id → session_ids` 的索引（Redis set 或 MySQL 表）来支持「列出用户所有会话」。
